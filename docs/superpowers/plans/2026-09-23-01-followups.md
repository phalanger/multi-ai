# 01 计划遗留事项（供后续计划引用）

来源：01-protocol-state 执行过程中各任务审查与最终审查的裁决。
写 02-probe、04-app 计划时必须逐条处理本文件。

## 02-probe 必须处理

已在 02-probe 计划中处理（见该计划“01 遗留事项的处理”表）。

- **P1 hook 事件的 `spool_offset`**：每个来自 hook 的 `AgentEvent`
  都必须带 `spool_offset`（由 spool 读取器统一分配）。
  做不到时，Tracker 需改为 `last_hook_ms = max(旧值, ts)`，
  防止带/不带 offset 的事件混合时权威窗口回退。
- **P2 规则编译错误缺少上下文**：`CompiledRules::compile`
  的错误要带上 agent 名与规则，并转为 `ProbeMsg::Error`。
- **P3 未知 `type` 的消息**：按行处理、不致命；
  记录错误后继续读下一行，不断开连接。
- **P4 识别出 agent pane 时上报**：首次识别即发送
  `state = unknown` 的 `AgentEvent`，
  保证无 hook、屏幕稳定的 agent 也出现在 UI。
- **P5 `SetRules` 热更新**：收到新规则后清空 `ScrapeTracker`
  （或逐个 `forget`），避免 agent 名变化后共用历史。
- **P6 标题与命令共用 `title_patterns`**：根据 spike 屏幕样本
  决定是否新增 `command_patterns`（带 `serde(default)`，向后兼容）。

## 04-app 必须处理

- **A1 时间来源混用**：明确 `since_ms`（探针主机时钟）与
  `pane_gone(now_ms)`（应用时钟）的来源；跨主机比较时考虑时钟偏差。
- **A2 Tracker 缺少遍历与删除**：新增 `agents()` 迭代器与
  `remove()`，供 UI 树展示全部 agent 并清理已退出记录。
